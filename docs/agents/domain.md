# Domain docs

For skills that read a repo's domain docs before exploring it.

- **Vocabulary.** There is no `GLOSSARY.md`. The project's terms are in the Language section of `failureship-grill-outcome.md`, and [AGENTS.md's Vocabulary section](../../AGENTS.md#vocabulary) is where the rule for using them lives.
- **Decisions.** There is no `docs/adr/` yet. The owner's design decisions are recorded in `failureship-grill-outcome.md`.
- **Adding an ADR.** If a decision needs a record of its own, start `docs/adr/` with `0001-<short-name>.md`: the context, the decision and its consequences, in a few paragraphs. Then update this file and AGENTS.md's Domain docs line to point at it.
